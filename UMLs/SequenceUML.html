SmartInventory — Sequence Diagrams

SD-1 · UC-01 — View Full Inventory

Employee.viewInventory() → Inventory.getAllItems() returns reference; InventorySystem iterates and prints each Item.

SD-2 · UC-02 — Search Item

Employee.searchItem() → Inventory.searchByName(). Case-insensitive substring match returns all matching Item pointers.

SD-3 · UC-03 — Make Transaction / Record Sale

Precondition: item located via UC-01 or UC-02. Step 6 fires only when post-sale qty ≤ threshold (auto-triggers UC-09). Transaction «create» uses constructor: Transaction(tId,iId,iName,qty,total,ts).

SD-4 · UC-04 — Add Item

Manager.addItem() → IS.generateItemId() (self-call) → «create» Item → Inventory.addItem(). Item constructor: Item(id,name,qty,price,thresh,cat).

SD-5 · UC-05 — Delete Item

Precondition: item found via UC-01/UC-02. Inventory.removeItem() erases item and clears associated RestockRequests.

SD-6 · UC-06 — Update Item Details

Precondition: item found via UC-01/UC-02. Inventory.updateItem() calls Item.setName/setPrice/setThreshold/setCategory. Quantity NOT changed.

SD-7 · UC-07 — Check Low Stock Alerts

Manager.checkLowStockAlerts() → Inventory.getLowStockItems() calls Item.isLowStock() on each item. isLowStock() returns quantity ≤ threshold.

SD-8 · UC-08 — Update Stock Quantity

Precondition: item found via UC-01/UC-02. Sets absolute quantity via Inventory.updateStockQuantity() → Item.setQuantity(). Distinct from UC-03 (sale deduction).

SD-9 · UC-09 — Review Restock Requests

RestockRequests auto-created by UC-03. Manager.fulfillRestockRequest() → Inventory.updateStockQuantity() → Inventory.clearRestockRequest() removes the fulfilled request.
